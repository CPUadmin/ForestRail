# Водитель дрезины

Открой `rail_worker.tscn` в Godot и выбери `AnimationPlayer → pole_stroke`. Это пробный зацикленный гребок длительностью 1,2 секунды. `RESET` хранит исходную позу.

Атлас `worker_parts.png` содержит девять прозрачных деталей. Сцена разбивает атлас на текстуры и задаёт центры вращения. Для головы она берёт профиль и кепку напрямую из исходного спрайта rail_worker_side.png. Для новой позы ставь ключи на узлы суставов: `Hips`, `Neck`, `Shoulder`, `Elbow`, `Wrist`, `Hip`, `Knee` и `Ankle`. На каждом запястье есть кисть с хватом (`Grip`) и открытая кисть (`OpenHand`). Переключай их свойство `visible`.

Персонаж смотрит вправо. Для разворота отрази корневой узел по X. Начало координат находится у настила. Метки `GripPoint` на запястьях показывают положение шеста внутри кулака.

Пробный цикл показывает работу шарниров. Синхронизацию с шестом и игровой анимацией нужно настроить при подключении сцены.
