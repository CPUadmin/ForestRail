# Ночной план автономной работы (05.11.2026)

Поручение владельца: работать самостоятельно, пока не кончится лимит или не сядет батарея, часто сохраняться (коммиты, копия на GitHub веткой `main`), вести план по вехам, компьютер не пускать в сон. Утром владелец проверяет.

## Правила на ночь
1. **Только безопасное:** коммиты и `git push origin main` (приватный репозиторий, это резервная копия). **Без** тегов, релизов на GitHub, установки в `%LOCALAPPDATA%\Programs` и смены ярлыка: выпуск только по слову владельца.
2. Одна задача = один маленький коммит; перед коммитом прогон затронутых наборов `tools/run_checks.py`; красный набор не коммитится.
3. Чужое не трогать (`assets/art_consists`, `qa/visual_audit_1104`, `Temp\...`), `git add -A` не использовать.
4. Крупные решения по экономике и геймплею не принимать молча: записывать как предложение в этот файл и в `ROADMAP_RU.md`, не включать в игру.
5. Картинки, которые трудно нарисовать, не рисовать кодом: готовить пакеты для GPT (`tools/art_sources/briefs`, `ART_QUEUE.md`).
6. Итог ночи писать внизу этого файла («Журнал»): что сделано, что проверено, что нет.
