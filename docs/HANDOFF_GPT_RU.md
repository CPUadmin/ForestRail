## Кто владелец и как с ним работать

- Владелец пишет по-русски, любит простое, прямое и честное общение. Ты и ведущий разработчик, и геймдизайнер.
- **Приоритеты:** баги, потом геймплей, потом визуал, потом новое. Крупные решения по экономике и геймплею сначала предлагай. Не выдавай непроверенное за проверенное.
- **Одна задача, один небольшой коммит.** Не делай `git add -A`: в папке лежат чужие незакоммиченные файлы (`ForestRail/assets/art_consists`, `qa/visual_audit_1104`), их не трогай.
- **Самое важное правило про картинки:** сложные картинки не рисуй кодом, готовь промпт для генерации изображений (папка `tools/art_sources`, очередь `ART_QUEUE.md`). Владелец только кидает один промпт в GPT, всё остальное делаешь ты: комплекты, приёмка, подключение.
- Все картинки должны быть с **сильным объёмом** (крупный рельеф, глубокие тени, свет сверху-слева).
- Владелец ругается матом, это норма, не обижайся. Михалыч в игре говорит с переключателем «крепкие выражения».

## Как запускать проверки

```bash
python tools/run_checks.py "<путь к Godot_v4.7.2-stable_win64.exe>" --manual-run --report-dir <временная папка> --suite check_model,check_casino_view
```

Наборы лежат в `ForestRail/tests/` (`check_*.gd`), имя набора добавлено в списки `tools/run_checks.py` и `main.gd` (`--qa-suite`). Снимки пишутся в `<report-dir>/<имя>/`. Кампания: `--suite drive_campaign` (150 с, проходит 13 из 13). Оконные наборы иногда падают из-за фокуса окна: перезапусти. `check_skins` падает в собранной сборке по замыслу.

## Как выпускать версию (проверено, делает Claude каждый раз)

1. Подними `config/version` в `ForestRail/project.godot`, допиши раздел в `docs/CHANGELOG_RU.md`, закоммить.
2. Собирай **из чистой копии коммита**: `git worktree add <папка> HEAD`, скопируй вручную `tools/templates/windows_release_x86_64.exe` в `<папка>/tools/templates/`.
3. `godot --headless --path <папка>/ForestRail --import` (может упасть с Segmentation fault, это безвредно, экспорт всё равно работает), затем `--export-release "Windows Desktop" <экспорт>\ForestRail.exe`.
4. Проверь собранный exe: `run_checks.py <exe> --exported --suite check_model,check_casino_view,...`.
5. Скопируй в `%LOCALAPPDATA%\Programs\ForestRail\<версия>\ForestRail.exe`, перенаправь ярлык «Лесная колея» на рабочем столе (PowerShell `WScript.Shell`).
6. `git tag v<версия>`, `git push origin main v<версия>`, архив `ForestRail-<версия>-windows.zip` и `gh release create ... --prerelease`. Копию архива положи в `release/` (там держи только последнюю). Репозиторий приватный: друзьям отдавай архив, не ссылку.
