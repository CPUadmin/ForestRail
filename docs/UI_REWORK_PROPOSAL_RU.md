# Переработка расположения кнопок и устройства интерфейса «Лесной колеи»

Автор: арт-директор / UX. Дата: 2026-11-08. Для: владельца.
Файлы игры не менялись. Это задание на будущие коммиты.
Что здесь: **где стоят кнопки, как сгруппированы, что объединено, что убрано, что стало жестом, клавишей или кликом по предмету.** Покраску и новый набор стилей не трогаем: палитра и кнопки из `ui_kit.gd` остаются, раздел 9 только про читаемость.

## 0. Главное

1. Сейчас игрок видит **до 35 кнопок сразу** (мастерская), **14-19** (депо), **5-13** (станция). Больше половины дублируют друг друга: «Улучшить» = вкладка «Мастерская» = клик по машине = клик по светящейся точке.
2. Идея: **один экран = одно главное действие. Остальное либо на самом предмете в мире, либо клавиша, либо спрятано до запроса.** На экране остаются сцена и одна главная кнопка.
3. Глобальных кнопок в рейсе остаётся одна: **☰** (пауза). «Карта», «Кабина», «Сохранить», «Отправиться», «Выгрузить», «Улучшить» убираются как кнопки.
4. Депо становится одной комнатой: машина по центру, заказ справа, остальное (гараж, мастерская, вагоны, казик) это предметы комнаты. Вместо 5-6 вкладок-плиток по 96 px: клик по предмету.
5. Внедряем маленькими шагами: сначала чистка дублей (S-размер, заметно сразу), потом перекладка.

## 1. Правила размещения (одни на все экраны)

| № | Правило |
|---|---|
| R1 | **Одна главная кнопка на экран.** В карточке/окне она внизу справа, залитая (стиль `PrimaryAction`). В мире (рейс, станция) главной кнопки нет: действие это движение. |
| R2 | **Второстепенное** стоит у предмета, к которому относится (над вывеской станции, над хвостом состава, у детали машины) или в карточке под главной как текстовая ссылка. Не больше 2 на карточку. |
| R3 | **Глобальных кнопок одна: ☰** (верх справа, 40 px). Остальное: горячая клавиша или клик по предмету. |
| R4 | **Недоступное прячем, а не серим.** Причина («сначала остановись», «нет места») в одной строке контекста или в подсказке над предметом. Серая «Развернуть» без объяснения уходит. |
| R5 | **Один путь к действию** + клавиша. Дубль допустим только как клавиша или клик по предмету, не как вторая кнопка. |
| R6 | Выбор из 2-3 вариантов: переключатель-сегмент. Больше трёх: список или «Ещё ▾». |
| R7 | **Необратимое** (отмена рейса, новая игра поверх сохранения) стоит слева от главной, тихим стилем, с подтверждением. Всё остальное без диалога (см. развилку В). |
| R8 | В поле зрения не более **5 интерактивных элементов** без прокрутки (не считая предметов мира). В карточке не больше 6 строк текста; остальное по запросу («Подробнее ▾», Tab, наведение). |
| R9 | **Закрытие окна: Esc, клик вне окна, ✕ в углу.** Кнопок «Назад», «Закрыть», «Понятно» нет (кроме полноэкранной карты, где уже есть «Закрыть [M / Esc]»). |
| R10 | **Рамки и пульты.** Снаружи пультов нет, сложное управление в кабине, на машине два рычага. Плашки и чипы не ставим в зону машины (поезд + 60 px). Допускается только подсказка над машиной. |
| R11 | **Окна и масштаб:** 1280×720 и 1600×900, текст 100/125/150 %. Все видимые кнопки внутри окна, ☰ ≤ 46 px высотой, постоянные панели HUD ≤ 22 % высоты (цель: ≤ 14 %). Чипы переносятся, не растут за край. |
| R12 | **Подсказка при наведении всегда имеет клавиатурный эквивалент** (Tab удерживать = показать сводку), чтобы не было «знания только для мыши». |

### 4.2 Депо (комната)

```
┌──────────────────────────────────────────────────────────────────────────────┐
│ Депо · Лесная      5000 монет · 0/10 рейсов · 🔩 15                     [☰] │ <- 1 строка
│                                                                              │
│  (стена: инструменты = Мастерская, доска = Заказы, дверь = Казик)            │
│                                                                              │
│  [‹]  Ручная дрезина  [›]                         ┌────────────────────────┐ │
│       180 кг · 2 места                            │ ОСНОВНОЙ РЕЙС · M01    │ │
│                                                   │ Первый рейс · 0,9 км   │ │
│   ◉      ◉   ◉   (точки на машине = детали)       │ Лесная → Сосновый разъезд│
│      ┌──────────────┐ ┌──────┐                    │ Мешок муки × 2         │ │
│  ════╡ машина        ╞═╡ + W  ╞══ рельсы ═══      │ Награда до 360 · ровно │ │
│      └──────────────┘ └──────┘                    │       [ К погрузке → ] │ │
│                       ^ «+ вагон · 120» (призрак) │ Все заказы (4) ▾       │ │
│  [Заправить · 40]  <- только если бак не полон    │ Выехать без заказа     │ │
│                                                   └────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────────────┘
```

Режимы комнаты (клик по предмету открывает правую панель, Esc возвращает в комнату):

| Предмет | Что открывается | Кнопок в панели |
|---|---|---|
| Машина или точка на ней | **Мастерская**: поповер выбранной детали (название, лампы уровня ○●, «до → после», цена) + схема износа | «Улучшить · N» (главная), «или болтами» (ссылка), «Починить всё · N» |
| Стрелки ‹ › у машины (или A / D) | **Гараж**: машины листаются стойкой; закрытая стоит силуэтом с ценой | «Купить · N» (только на закрытой) |
| Сцепка или хвост состава | **Состав**: клик по сцепке цепляет/отцепляет (уже есть) | «+ вагон · N» (призрак) |
| Доска заказов на стене / «Все заказы (4)» | **Заказы**: список из 4 карточек в одну строку каждая (название, маршрут, награда), в раскрытой карточке «Взять» | «Взять» на раскрытой |
| Чип «🔩 N» в шапке | Приёмка болтов (то же окно) | как сейчас |
| Дверь/вывеска «Казик» | Экран казика | см. 4.6 |
| Страница «Рекорды» | Вторая страница доски, только если `records_open()` | 0 |

Правила размещения депо:
- Главная кнопка одна и всегда в карточке заказа справа внизу. При активном рейсе вместо неё «Продолжить рейс →», а «Отменить рейс» ссылкой слева.
- Левая плашка с описанием машины уходит. Название и «180 кг · 2 места» одной строкой под машиной; полные характеристики при наведении (R12: Tab).
- Подсказка у вывесок: подписи «Доска», «Мастерская», «Казик» всегда видны мелким текстом на предметах (иначе мышь не найдёт), при наведении предмет подсвечивается.
- Имена состояний `tab` («Рейсы», «Гараж», «Состав», «Улучшения», «Казик», «Рекорды») **сохраняются как внутренние**: тесты ставят `game.tab` напрямую.

### 4.3 Станция и погрузка

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                                          [☰] │
│  Сосновый разъезд · выгрузить: Мешок муки × 1        <- одна строка контекста│
│                                                       (пропадает, когда всё) │
│          ┌───────────────────────────┐                                       │
│          │  Сосновый разъезд         │  [⛽ Заправка · 12]  [↻ Развернуть R] │ <- чипы на вывеске,
│          └───────────────────────────┘                       только если можно │
│                                                                              │
│   ══ платформа ═════ [груз] [груз] ══════════                                │
│   ══ рельсы ═════ [поезд] ═ тормоз/рычаги как сейчас ═════                   │
│                                                                              │
│  [груз ×2] [груз ×1]   Везём 2 / 2 · 215 кг · 360 монет      <- полоса грузов│
│  (спидометр) │ (лента маршрута · «Готов: дай ход») │ (топливо)     <- HUD    │
└──────────────────────────────────────────────────────────────────────────────┘
```

Правила станции:
- Груз перетаскивается на платформу/вагон. Двойной клик по грузу = выгрузить (если станция подходит; иначе строка контекста объясняет, куда он едет).
- «Отправиться» нет: лампа в ленте «Готов: дай ход» загорается, когда всё погружено. Клавиша Enter как запасной путь.
- Чипы стоят **на вывеске станции и над платформой**, не на машине (R10). Чип виден только когда действие возможно (R4).
- Станция A после возвращения: чип «Заехать в депо →» на вывеске; в погрузке тот же чип (отмена рейса).
- Ход назад «Тяга ← →»: один переключатель с текущим направлением, виден на остановке.
- Без кнопок: «Сохранить» (автосейв, лампа «сохранено» в ленте на 2 с), «Сбить иней» (I), «Выгрузить выбранный».

### 4.4 HUD в рейсе

```
┌──────────────────────────────────────────────────────────────────────────────┐
│                                                                          [☰] │
│                       «Колёса буксуют»   <- тост, 1 строка, 3 с, заменяет прежний
│                                                                              │
│                           (мир, поезд, мышь на машине)                       │
│                          при наведении: [Кабина · E]                          │
│                                                                              │
├──────────────────────────────────────────────────────────────────────────────┤
│ ◜ 42 км/ч ◝ │ ●══▶────○─────────○   ДАЛЕЕ · Лесная · 100 м   ▲+3% │ ▮▮▮▯ 0,65/0,7 л │(◎)│ <- ≤ 14 %
└──────────────────────────────────────────────────────────────────────────────┘
```

| Зона | Что видно всегда | Что по запросу (Tab / наведение) |
|---|---|---|
| Левая (спидометр) | стрелка + число км/ч, лампа износа | лимит скорости, передача (только мотор) |
| Середина (лента) | станции, поезд, «ДАЛЕЕ · станция · метры», подъём впереди, срок рейса (когда меньше 20 %) | часы, погода, тормозной путь, длина рейса |
| Правая (топливо) | шкала + число, тип (бензин / пар / воздух) | масса состава, груз, уклон, тормоз % |
| Круглый чип (◎) | только с гаджетом: рывок/нитро/кошка с кольцом заряда | клавиша в подсказке |
| Верх | **ничего**, кроме ☰ и тоста | — |

Правила HUD:
- Верхняя строка исчезает: её содержимое уже есть в ленте. Это освобождает верх кадра.
- Тост одна строка, одно сообщение за раз, без наложения на подсказку.
- Подсказка рычагов (текст обучения) остаётся только при включённых подсказках, не более 2 строк, над ☰-зоной, не в зоне машины.
- Tab (удерживать) показывает сводную карточку над лентой; отпустили, пропала.

| 10 | **Казик как дверь:** вкладка уходит, внутри «Деп» = клик по мешку, «Назад» = ✕/Esc | M (+ картинки) | | `check_casino_view`, `check_album_view` |
| 11 | **Станция в мире:** чипы на вывеске (заправка, депо, развернуть), узкая полоса грузов, лента «Готов: дай ход» | L | | `check_station_service` (искать чип, а не кнопку в `cargo_actions`) |
| 12 | **Нижняя лента ≤ 14 %, Tab-сводка, тост одной строкой** | L | | `check_layout_p7` (постоянные панели; порог 22 % остаётся верхней планкой), `check_instruments` |

Порядок по эффекту: **1 → 4 → 2 → 3 → 5 → 6а → 6б → 7 → 8 → 11 → 12 → остальное.** Шаги 1-3 безопасны (S), дают видимую чистку за один вечер; шаг 4 меняет больше всего тестов, поэтому после того, как 1-3 зелёные.

Как не сломать тесты: кнопки остаются `Button` с тем же текстом, пока шаг не помечен «обновить тест»; «выбрана» = `disabled`; чипы-ссылки делаются `Button` (flat) с тем же текстом; внутренние имена `tab` и `modal_kind` не переименовывать; новые клавиши добавлять с проверкой в `load_settings`.

## 9. Читаемость (без нового стиля)

| Что | Правило |
|---|---|
| Рамки | одна рамка на панель; внутри карточки без рамок, разделитель отступом 12-16 px |
| Кнопки | в поле зрения два вида: главная (залитая) и тихая (текст/контур). Все «ящики» с кромкой оставить только для главной |
| Размеры текста | заголовок 28, основной 20, мелкий не меньше 16; цена и награда крупнее соседних строк |
| Отступы | между блоками не меньше 16 px при 100 % текста; при 150 % блоки переносятся, не сжимаются |
| Подсказки | при наведении, 0,4 с задержки, над предметом, не в зоне машины |
| Цвет | палитра `ui_kit.gd` не меняется; смысл не только цветом (значок или слово) |

Итог: интерфейс не получает нового стиля, он **теряет** кнопки и рамки; поэтому изменение дешёвое по ассетам и не требует правки `ui_kit.gd`, кроме добавления вида «текстовая ссылка» (flat без рамки).
