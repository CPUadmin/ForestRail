## 1. Как читать номер версии

```
  1 . 3 . 2 . 1 - B2
  │   │   │   │    └─ СБОРКА: A = рабочая (только у меня), B1, B2… = тебе на пробу, без буквы = выпуск
  │   │   │   └────── ПРАВКА: исправления без новых возможностей (0, 1, 2…)
  │   │   └────────── ШАГ: одна готовая понятная вещь внутри выпуска
  │   └────────────── ВЫПУСК: тема («Повреждения», «Интерфейс»…)
  └────────────────── ЭПОХА: 1 = нынешняя графика; 2 = большая переделка графики
```

Примеры:
- `1.4.1.0-B1` = выпуск «Повреждения», шаг 1 «лампа и значки», первая пробная сборка тебе.
- `1.4.1.0` = тот же шаг, выпущенный игрокам.
- `1.4.1.1` = исправление в этом шаге после твоей пробы.
- Тег в git: `v1.4.1.0`. Прежние теги `v1.2.0-preview.NN` остаются как есть.

Правила:
1. **Один шаг = один понятный результат** (то, что ты увидишь в игре) и один-три коммита.
2. **Ничего не выпускаю без твоего слова «выпускай»**. Сборки `-B` делаю для тебя сами и ставлю ярлык, когда ты просишь.
3. Каждая строка ниже имеет **размер**: S (≈час), M (≈полдня), L (≈день и больше) и **кто**: Я, GPT, ТЫ, ПОМ (помощники-агенты).
4. Перед каждым выпуском проходят **ворота качества** (раздел 4).

## 4. Ворота качества (проходит каждый выпуск)

Эти пункты родились из разбора ошибок (`POSTMORTEM_2026-11-07_RU.md`):

1. **Чистая машина:** нет лишних процессов `run_all4`, `run_checks`, `Godot`; наборы не запускаю параллельно.
2. **Все наборы проверок** (84), красный только известный `check_save_p8`.
3. **Жизненный цикл** (`check_lifecycle`): у каждой машины двигатель включается и тушится, расходники возвращаются, в обоих режимах.
4. **Визуальная приёмка:** листы `probe_visual_audit` смотрю **крупно** по всем девяти машинам: день, ночь с фонарём, ход, торможение, юз, депо.
5. **Замер кадра** (с выпуска 1.3): бюджет мс на кадр не превышен.
6. **Сборка из чистой копии**, проверка готового exe, **в логах готового exe нет «No loader found» и «Failed loading»** (наборы зелёные и при потерянных картинках: так чуть не исключили живую картинку цеппелина), установка (последние 3), ярлык, тег, архив, релиз GitHub.
