# Уточнение управления после P2

Пользователь просит выбирать направление ручной дрезины действием на рычаг и переключать передачи без обязательной остановки.

Для нашей ручной дрезины выбран двусторонний кривошипный привод с постоянной сборочной ветвью. Направление должно следовать из знака вращения и приложения силы при данной фазе. Одинаковое движение хвата вверх или вниз при разных фазах может давать разный момент. Смена движения руки посреди хода может замедлять и разворачивать привод; смена движения на крайнем положении нужна для продолжения оборота. Быстрый обратный рывок не должен мгновенно менять скорость тяжёлого состава.

Такой выбор направления с места согласуется с описанием изготовителя [Handcar Tours, раздел Common Questions](https://handcar.com/our-vision/): первый толчок задаёт вращение кривошипа, дальнейшее качание его поддерживает. Это источник по конкретной конструкции, а не универсальное правило для всех дрезин. Существовали и другие приводы с переключаемыми храповиками, например [US642857A](https://patents.google.com/patent/US642857A/en); их режим свободного рычага не переносится автоматически на наш жёстко связанный кривошип.

Проверки для P4:

- одна исходная фаза, противоположное усилие при пуске — противоположное вращение;
- смена движения руки в середине хода — непрерывные фаза и скорость, отрицательная работа замедляет состав;
- правильная смена хода у крайнего положения — продолжение полного оборота;
- при накате колёса двигают механизм, отпускание мыши не останавливает его отдельно;
- полный тормоз удерживает привод, скрытого выбора реверса с затянутым тормозом не требуется;
- в точной мёртвой точке отдельно виден ограниченный способ подталкивания.

Это выполняется в P4 после проверки геометрии P3. Старая выдача тяги за движение мыши и отдельный реверсор в preview.3 пока остаются переходной реализацией.

На моторной дрезине смена передач на ходу уже разрешена при подаче ниже 15%. Новый тест проверяет 1→2 при скорости 3 м/с, отсутствие сброса скорости и запрет смены под нагрузкой. В P5 нужно сделать момент переключения понятным по состоянию пульта и звуку. Для ручной машины P3 использует одно фиксированное отношение на стенде; дополнительные передачи требуют отдельного согласованного привода, а не произвольного изменения скорости.
