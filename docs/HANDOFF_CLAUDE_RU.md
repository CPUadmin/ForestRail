**Как проверять:**
- Тесты: `python tools/run_checks.py <путь к Godot> --suite <список>`. Наборы (18): check_model, check_physics, drive_campaign, check_handcar_revision, check_art_v3, check_mechanism, check_handcar_drive, check_save_p8 (нужен `--migration-save=` с настоящим старым сохранением, без него выходит с кодом 2), check_interaction, check_instruments, check_presentation, check_station_service, check_world_geometry, check_mechanism_bench, check_handcar_input, check_motor_controls, check_loading_selection, check_layout_p7. Оконные наборы требуют обычного оконного сеанса. run_checks.py пишет отчёты в `qa/` — не коммить их случайно.
- Тесты покупают технику через `tests/fixtures.gd` (`equip(model, id)`): машина + полный набор вагонов без изменения денег. Экономику честно (свободными рейсами) проверяет check_model.
- Скриншоты для визуальной проверки: снимай экраны игры (меню, депо, погрузка, езда, станция, карта, локомотив) при 1600×900 и при 1280×720 с текстом 150%. Режим растяжения canvas_items: логический размер всегда 1600×900.
- После правок ассетов нужен `godot --headless --path ForestRail --import`, иначе текстуры не найдутся.
