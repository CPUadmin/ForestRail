# Реализация ТЗ 2.1

Игра использует исходные названия станций, заказы M01–M10, цены техники, грузовые массы и 16 веток улучшений из предоставленных данных. Исходное ТЗ сохранено рядом без изменений.

Дополнение пользователя: моторная дрезина использует бензин, локомотив — электроэнергию. Для локомотива реализована батарея 0,6 кВт·ч, бесплатная зарядка в депо и рекуперация 25% фактической энергии торможения при нулевой подаче. Ветка «Бак» отображается как «Аккумулятор», сохраняя две исходные цены и прибавку ёмкости +35% / +70%. Раздел топлива в исходном ТЗ для локомотива заменён этим правилом.

Дорога хранит интегрированное расстояние вдоль профиля, а не горизонтальную координату. Сила тяжести, сопротивление и масса учитываются под каждой машиной и каждым вагоном. Расчёт выполняется на фиксированных 60 Гц. Графика колёс привязана к пройденному расстоянию.

У ручного привода учитывается путь мыши, есть мёртвая зона при смене направления, ограничение скорости рычага, полезной работы и мощности. Камера и наклон кузова не порождают работу. Небольшая очередь движения выравнивает ввод между отрисовкой 30/60 FPS, не добавляя энергии без пользовательского движения.

Составы хранят конкретные ID вагонов. Присоединение вагона к другой машине снимает его с сохранённой конфигурации предыдущей. Уровни, бак и оставшиеся конфигурации принадлежат отдельным машинам.

Промежуточные станции принимают только предназначенные им предметы. Ошибочный перенос не меняет состояние груза. Оплата фиксируется после последней доставки, но выдаётся только дома. Идентификатор оплаченного рейса хранится вместе с новым балансом.

Основной файл сохранения обновляется через проверенный временный файл. Исправный основной файл сначала копируется в backup. Повреждённые основные файлы не попадают поверх backup. Загрузка проверяет структуру дороги, гараж, состав, предметы и диапазоны чисел до замены текущего состояния.

Предоставленные кузова, колёса, грузы, лес, станции и звуки включены в игру. Подвижные SVG-рукояти вращаются отдельно от неподвижных опор. Электрическое оборудование локомотива обозначено дополнительным блоком с символом молнии.
