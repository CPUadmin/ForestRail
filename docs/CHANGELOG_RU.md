# История версий «Лесной колеи»

Формат: новейшая версия сверху; у каждой версии дата, метка (тег) в git вида `v<версия>` и главное для игрока. Подробности по задачам — в `AI_IMPLEMENTATION_STAGES_v3.md` и `HANDOFF_CLAUDE_RU.md`, планы — в `ROADMAP_RU.md`. Версии `1.2.0-preview.N` — рабочие сборки: они прошли автоматические проверки, но не приняты человеком целиком; приёмка идёт по вехам плана.

## Как вести историю дальше

1. Каждая сборка получает версию в `ForestRail/project.godot` (`config/version`).
2. Коммит, который меняет версию, получает метку `v<версия>` (annotated tag) и запись сверху этого файла.
3. Метки с `preview` публикуются на GitHub как предварительные релизы; когда веха плана принята владельцем, её последняя сборка становится стабильной `1.2.x` (метка без `preview`). Ветка `main` — текущая линия разработки (с 01.11.2026).
4. Скрипт `tools/make_releases.ps1` создаёт релизы GitHub по меткам из этого файла (нужен `gh`).
