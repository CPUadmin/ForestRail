# Правила проекта «Лесная колея»

Свод правил из всех документов (сверка 14.11.2026). Где старые документы спорили, решение принято здесь (судья: Claude по поручению владельца) и помечено ⚖️. Короткая версия для ИИ лежит в `CLAUDE.md`.

## Работа

1. **Первое правило владельца:** пользоваться навыками, плагинами и помощниками. Перед сложной частью попросить владельца переключить модель.
2. Порядок важности: ошибки → геймплей → вид → новое.
3. Крупные решения по игре и экономике сначала предлагаются, вопросы владельцу короткие «А / Б / В» с советом.
4. Отчёт: сначала что видно в игре, потом что не проверено. Автотесты не равны пробе человеком, оценка по коду не равна замеру.
5. Один шаг = один понятный результат = 1–3 небольших коммита.
6. ⚖️ **Ветка одна: `main`.** Старые ветки `claude/visual-v3` и `codex/spec-v3-p8` из документов больше не используются.
7. ⚖️ **Пуш в `main` можно после зелёных проверок** (так шло с 05.11). Тег, релиз GitHub, установка и ярлык делаются только по слову владельца.
8. Коммит только по именам файлов, никогда `git add -A`. Не трогать чужие неотслеженные файлы. `outputs/`, `work/`, `release/` и отчёты в `qa/` не коммитятся (кроме тех, что уже в git).
9. Не объявлять этап пройденным при упавшей проверке. Не править тесты под неверное поведение.

## Проверки

10. Тесты строго по одному, перед стартом нет процессов Godot (`tools/run_all_checks.py` следит сам).
11. Ворота выпуска: все наборы зелёные (кроме `check_save_p8`, ему нужно старое сохранение), `check_lifecycle` в карьере и в творческом, визуальная проверка листов крупно по всем 9 машинам (`tools/visual_audit.py`), бюджет кадра (`check_perf_budget`), сборка из чистой копии без «No loader found» (`tools/build_trial.py`), заметки выпуска совпадают с игрой.
12. Новая версия читает старые сохранения, миграции проверяются копией старого сохранения. Сохранения и файлы владельца не перезаписываются.

## Версии и выпуски

13. Номер `ЭПОХА.ВЫПУСК.ШАГ.ПРАВКА`, пробные сборки `-B1`, `-B2`… Старые теги `v1.2.0-preview.NN` остаются.
14. Выпуск только по слову владельца «выпускай».
15. Старые версии в папке установки не удаляются. На GitHub выкладывается каждая третья версия (решение 14.11).

## Код и данные

16. Числа в интерфейсе берутся из данных, а не пишутся руками.
17. Размеры машин из единого каталога `ForestRail/data/object_dimensions.json`: ручная 2,4 м, моторная 3,6 м, локомотив около 4 м, вагон 2,8 м.
18. Концы строк: LF везде, CRLF у `.bat`/`.cmd`/`.ps1`.
19. Имена: документы `*_RU.md`; в текстах «Лесная колея», в коде `ForestRail`.

## Картинки

20. Сложные картинки рисует GPT по заданию (очередь `tools/art_sources/ART_QUEUE.md`, замечания `FEEDBACK_FOR_GPT.md`), а не код. ⚖️ Картинки, сделанные до 04.11 встроенным генератором, остаются как есть, новые только через GPT.
21. ⚖️ **На картинках нет букв и цифр.** Номера, названия карт Таро, вывески и кнопки ставит игра. Старые промпты казика с «рукописными надписями» и рамкой с римской цифрой отменены.
22. ⚖️ **Форматы только 1:1, 3:2, 2:3.** Нужный размер (например 600×360) игра получает обрезкой.
23. Фон `#FF00FF`, свет, искры и дым на `#000000`. Один предмет по центру, поля от 8%, стиль тёплый, потёртый, сильный объём, латунь и тёмное дерево.
24. Картинки игры без сжатия с потерями (решение владельца 14.11).
25. Анимации делаются кодом в Godot, от GPT нужны неподвижные детали.

## Звук и лицензии

26. Каждый внешний звук или шрифт записывается в `docs/AUDIO_CREDITS_RU.md` с автором и лицензией, скачивается только нужное после проверки лицензии. Лицензии Godot лежат в `docs/GODOT_LICENSE.txt` и `docs/GODOT_COPYRIGHT.txt`.

## Тон и казик

27. Тон тёплый и ироничный, без давления. Шансы не выдаются за гарантии.
28. В казике никогда «не выиграешь», только «вот-вот» и «почти». Нет «ещё раз!», таймеров и мигающих приманок после проигрыша, «хватит» доступно всегда.
29. ⚖️ **Жетоны за деньги не продаются** (вариант Б из `KAZIK_ECONOMY_RU.md` отклонён).
30. ⚖️ **Числа казика берутся из `KAZIK_ODDS_RU.md`**, он главнее `KAZIK_RU.md`. Гаджеты достаются только из казика.
31. Реплики свои, без цитат известных людей.
