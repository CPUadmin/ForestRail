# Размеры и размещение P2

Единый каталог: `ForestRail/data/object_dimensions.json`. Базовый масштаб — 96 px/м в `world_geometry.gd`. Камера применяется один раз. Новые PNG получены через Imagegen и сохранены без правки пикселей; видимые области и равномерный масштаб задаются отдельно. Параметры итоговой картинки измерены после генерации.

| Объект | Фактический размер |
|---|---|
| Ручная дрезина | длина 2,40 м, настил 0,572 м, колёса 0,42 м |
| Рычаг ручной дрезины | ширина 1,90 м, ось 1,45 м над рельсом |
| Моторная дрезина | длина 2,80 м, настил 0,607 м, колёса 0,42 м |
| Электролокомотив | длина 4,00 м, крыша 2,495 м, колёса 0,55 м |
| Грузовой вагон | длина 2,80 м, настил 0,635 м |
| Сцепки | зазор между кузовами 0,30 м; концевое крепление 0,15 м |
| Мешок / ящик | высота 0,65 / 0,55 м; исходные пропорции сохранены |
| Брёвна | длина 1,80 м; стопки стоят друг на друге |
| Тормоз / газ / передача / пуск | длина от оси до хвата 0,65 / 0,28 / 0,28 / 0,06 м |
| Дверь | 2,05 м |
| Станционный домик | ширина 11,565 м, высота 3,211 м |
| Депо | ширина 11,866 м, высота 3,985 м; ворота выше локомотива |
| Навес | ширина 15,907 м, высота 4,00 м |
| Приёмная платформа | длина 18,00 м, верх 0,55 м над рельсом |

Расстояния между центрами вычисляются из двух полудлин и зазора, включая обратное направление состава. Зона обслуживания использует те же размеры. Кузов ориентируется по двум точкам контакта осей с маршрутом; сцепка рисуется между креплениями, преобразованными теми же матрицами.

На технике видны небольшие органы управления. Невидимая область захвата — 48 px по диаметру. Для моторных машин кнопка «Пульт [C]» открывает крупное управление с теми же состояниями и обработкой мыши. C, Esc или заголовок закрывают его; карта и пауза отменяют захват. Это промежуточный пульт P2: полная компоновка интерфейса остаётся в P5/P7.

Стенд и кадры создаёт `check_world_geometry.gd` из настоящего рендера Godot. Проверка включает три масштаба, четыре участка пути, обе ориентации состава, размеры груза, захват рукоятей через UI и запуск/передачу/подачу/тормоз в крупном пульте. Численный отчёт: `qa/world_geometry_p2.json`. Изображения: `docs/screenshots/p2_*.png`.

Старая модель ручного привода сохранена до P3/P4. Прохождение её прежних проверок не доказывает непрерывность фазы или правильный накат механизма. Проверка новичком не проведена.
