# Учёт ассетов из соседнего чата

Проверен чат «Придумай игру про дрезину» (`01a17dc9-4ff2-7713-96f0-63fb09f7891f`) и его 48 исходных PNG. Для каждого найдена побайтово совпадающая копия в проекте. Пропущенных файлов нет. Проверка сохранена в `qa/supplied_assets_audit.json`; воспроизводится `tools/audit_supplied_assets.py` с каталогом исходных генераций в параметре `--originals`.

| Комплект | Сохранено | Использование |
|---|---:|---|
| Отдельные объекты art_v3 | 28 / 28 | Механизм, колёса, сцепки, постройки, путь и параллакс. Кузова P2 заменяют четыре старых рисунка при отрисовке; оригиналы сохранены. Продольная ось предназначена для разобранного вида, в рабочем механизме используется её торец. |
| Иллюстрации и макеты | 13 / 13 | Полные исходные картинки в `outputs/ForestRail_DevSpec_v3/images`; используются как ориентиры по станциям, экрану поездки, депо и карте. Все изображения также сверены с `files.json` исходного комплекта Visuals_v1. |
| Ранние изображения | 7 / 7 | Атласы транспорта, леса, грузов и станционных деталей, фон, две ранние версии рычагов. Сохранены в `ForestRail/assets`; часть продолжает использоваться, часть заменена отдельными деталями art_v3. |

Ссылки на локальные файлы из старого манифеста также проверены. Число сохранённых файлов не означает, что каждый из них одновременно нарисован на экране. Иллюстрация с готовыми надписями и кнопками не подменяет работающий интерфейс; её перенос не завершает P5/P7. Оригинальные рисунки не удалены и не перезаписаны при создании P2/P3.

Текущие заменяющие ассеты P2 и их происхождение: `ForestRail/assets/art_p2/provenance.json`, `calibration_notes.json`. В P3 новые изображения не генерировались: изменены геометрия и равномерный масштаб существующего рычага.
