# Замеры кадра (база на 08.11.2026)

Набор `check_perf_budget` (шаг 1.3.1). Машина: AMD Ryzen 7 8745H, Radeon 780M; окно 1600×900. Числа: медиана / 95-й процентиль, миллисекунды.
Бюджет: порог = база ×1,3 по медиане и ×1,6 по p95 (плюс малый запас). База хранится в `qa/perf_baseline.json` на каждой машине отдельно (по имени процессора), в git не кладётся.

| Сцена | рисование сцены | фон мира | HUD | физика (за тик) |
|---|---|---|---|---|
| дорога, бензиновая с вагонами | 2,1 / 2,9 | 2,2 / 3,2 | 2,7 / 3,6 | 0,94 / 1,24 |
| кабина бензиновой | **9,4 / 11,8** | 2,2 / 3,2 | — | 1,0 / 1,3 |
| дорога, паровоз | 2,0 / 2,7 | 2,2 / 3,0 | 2,6 / 3,7 | 0,97 / 1,35 |
| цеппелин ночью | 2,0 / 2,8 | 2,2 / 3,2 | 2,7 / 3,7 | 1,1 / 1,5 |
| депо | 2,6 / 3,8 | **5,0 / 7,1** | — | — |

Что видно:
- **Кабина самая тяжёлая:** 9,4 мс на рисование (цель всех скриптов за кадр ≤ 8 мс). Это находки H9 и H10 аудита (статичная рама каждый кадр, много вызовов).
- **Фон мира в депо 5 мс** против 2,2 мс на дороге.
- **Физика 1,0 мс за тик** при цели ≤ 0,5.
- HUD 2,6 мс (цель ≈ 1).
- Полный кадр показывает 16,7 мс: это частота экрана (vsync не отключается из теста), поэтому честные числа только в столбцах по счётчикам.
