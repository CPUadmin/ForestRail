# ЗАДАНИЕ GPT: пакет П24 (шасси рельсового цеппелина)

Зачем: у рельсового цеппелина в игре нет колёс — он стоит на раме с двумя тележками (пружины и латунные колпаки, см. `ref_zeppelin_body.png`). Владелец хочет колёса, **лишь чуть похожие на шасси самолёта**, и чтобы они **немного амортизировали** (стойка пружинит на неровностях и при посадке). Игра соберёт шасси из деталей и сама будет двигать шток стойки и крутить колесо, поэтому детали нужны отдельно.

Посмотри `ref_zeppelin_body.png`: под каждым латунным колпаком тележки (их два) будет висеть одна стойка с колесом. Держи тот же металл, латунь, зелень #466c51, заклёпки и свет сверху-слева. Это всё ещё железнодорожное колесо (с ребордой, катится по рельсу), но с чертами авиационного: толстая тёмная шина поверх обода, дисковая ступица.

Общий стиль (правила в tools/art_sources/inbox/GPT_INSTRUCTIONS.txt): рисованный, тёплый, потёртый, сильный объём, без букв и цифр. Фон ровный #FF00FF, без теней на фоне, предмет по центру ячейки, поля не меньше 8%. Лист: равные ячейки, один предмет в ячейке, **один масштаб для всех деталей** (они собираются вместе), без линий сетки.

Клади в tools/art_sources/inbox/P24_zeppelin_gear/ (или архивом). В конце перечисли слабые.

### zep_gear.png (1:1, лист 2x2)
1 — **колесо**, строго сбоку, идеально круглое, ось точно в центре ячейки (игра его вращает): тёмная резиновая шина, под ней стальной обод с выступающей ребордой, латунный дисковый колпак ступицы с 6 болтами по кругу и заметной меткой (чтобы было видно вращение).
2 — **верхняя часть стойки**: вертикальный латунный цилиндр амортизатора с хомутами, сверху крепёжная проушина (крепится к колпаку тележки), снизу открытый торец, из которого выходит шток.
3 — **шток с вилкой**: вертикальный блестящий стальной шток (длиной примерно как верхняя часть), внизу вилка, обнимающая ось колеса (у вилки отверстие под ось ровно по центру низа детали). Ширина штока чуть меньше внутреннего диаметра цилиндра из детали 2.
4 — **шлиц-шарнир (ножницы)**: два коротких рычага на шарнире, соединяющие цилиндр и вилку, как у самолётной стойки (игра будет их складывать). Нарисуй в среднем положении.
