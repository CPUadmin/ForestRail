# Рабочее пространство для картинок (владелец, GPT и я)

Одна папка на всё: `tools/art_sources/`. Здесь комплекты заданий, входящие файлы от GPT, готовые вырезанные картинки и отчёты.

```
tools/art_sources/
  briefs/<пакет>/     задание для GPT: BRIEF_RU.md (для вас), TASK_FOR_GPT.md (одним файлом для GPT),
                      PROMPTS_FOR_GPT.txt (блоки для копирования), ref_* (кадры-образцы из игры)
  inbox/<пакет>/      СЮДА кладёте картинки от GPT (имена как в задании)
  inbox/_unsorted/    сюда можно бросить любые файлы с любыми именами, я разберу сам
  accepted/<пакет>/   результат: фон вырезан, обрезано, листы нарезаны на ячейки (делает скрипт)
  rejected/<пакет>/   что вернули и почему (reason.txt)
  reports/            отчёты приёмки и контактные листы (серый фон, видно прозрачность)
  art_tracker.json    статус каждой картинки
  visual_inventory.json   реестр всех визуальных элементов игры
  open_inbox.bat      двойной щелчок: открыть папку inbox
```

## Как это идёт (по шагам)

1. **Я** готовлю комплект пакета: `briefs/<пакет>/` (промпты, кадры-образцы, чек-лист).
2. **Вы** даёте GPT задание (вариант выбираете ниже), он генерирует картинки по одной.
3. **Вы** сохраняете файлы в `inbox/<пакет>/` (или в `_unsorted`, если имена другие) и пишете мне «П2 в inbox».
4. **Я** запускаю приёмку: проверка (фон, пропорция, поля, пустые ячейки листа, «шахматка» вместо прозрачности), вырезание пурпурного фона, снятие розовой каймы, обрезка, нарезка листов. Смотрю результат, по каждой картинке пишу «принято» или «вернуть» и одной фразой, что сказать GPT. Принятое подключаю в игру и показываю кадры «до и после».

## Что сказать GPT (три варианта, от простого к удобному)

**Вариант 1, работает сразу.** Откройте файл `briefs/<пакет>/PROMPTS_FOR_GPT.txt`, вставьте блок 0 с приложенными `ref_*`, дальше блоки по одному. Либо вставьте в чат целиком `TASK_FOR_GPT.md` и приложите `ref_*`: там всё одним куском, GPT отдаёт картинки по очереди.

**Вариант 2: «посмотри на GitHub», через подключение ChatGPT к GitHub.** Репозиторий приватный, поэтому по обычной ссылке GPT его не откроет. Если в вашем ChatGPT есть подключение GitHub (настройки, подключённые приложения), подключите к нему `CPUadmin/ForestRail` только на чтение и говорите так:

```text
Открой в репозитории CPUadmin/ForestRail (ветка main) файл tools/art_sources/briefs/P2_pole_sail/TASK_FOR_GPT.md, посмотри кадры ref_* рядом с ним и выполни задание.
```

Я не проверял, как это подключение работает у вас и умеет ли GPT открывать картинки из репозитория. Если не умеет, приложите `ref_*` вручную.

**Вариант 3: отдельный публичный репозиторий только для обмена** (например `ForestRail-art`), куда я выкладываю комплекты, а GPT открывает их по обычной ссылке. Это публикация, поэтому без вашего согласия я его не создаю. В нём ничего секретного (задания и кадры из игры).

Возврат файлов от GPT в любом варианте делаете вы: скачать картинку из чата и перетащить в `inbox/<пакет>/`. GPT сам записать в репозиторий не может, и ключей доступа ему давать не нужно.

## Команды для меня (приёмка)

```text
python tools/art_intake.py status                  таблица всех картинок и статусов
python tools/art_intake.py scan П2                 проверить входящие, ничего не менять
python tools/art_intake.py process П2              вырезать фон, обрезать, нарезать, обновить трекер, отчёт
python tools/art_intake.py prompts П2              пересобрать PROMPTS_FOR_GPT.txt и TASK_FOR_GPT.md из BRIEF_RU.md
python tools/art_intake.py assign <файл> <id>      привязать файл из _unsorted к картинке (P2-A1…)
python tools/art_intake.py accept <id>             отметить принятым
python tools/art_intake.py reject <id> "причина"   вернуть
```

Статусы: в списке, промпт готов, запрошено, получено, получено с проблемами, принято, отклонено, подключено.
