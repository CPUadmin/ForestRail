# Подготовка графики art_v3

Здесь сохранены вспомогательные материалы соседнего чата, в котором создавалась графика: измерение отверстий и осей, построение метаданных и материалов, каталог и отчёты проверок.

Готовый комплект, использующийся игрой, находится в `ForestRail/assets/art_v3/`. Для игры запускать эти вспомогательные скрипты не требуется. Некоторые исторические скрипты содержат пути исходной рабочей папки: перед повторным использованием их нужно настроить под свой компьютер. Сырые PNG и запросы генерации сохранены рядом с готовым комплектом.
