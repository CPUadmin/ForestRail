# Лесная колея: как тут всё устроено

Короткая памятка для владельца. Для Claude правила лежат в [CLAUDE.md](CLAUDE.md).

## Кнопки (папка `КНОПКИ`, двойной клик)

| Кнопка | Что делает | Сколько идёт |
|---|---|---|
| **Проверить всё** | все тесты игры по одному, в конце пишет «всё зелёное» или что красное | ~40 мин |
| **Собрать пробную версию** | собирает игру из последнего коммита в `release\trial\<версия>\ForestRail.exe` и проверяет её. Не устанавливает и не выпускает | 5–10 мин |
| **Снимки для проверки глазами** | кадры всех 9 машин (день, ночь, ход, тормоз, юз) и депо, открывает папку | ~1 мин |
| **Открыть картинки GPT** | папка входящих картинок и очередь заданий GPT | сразу |
| **Открыть план** | план простыми словами | сразу |

| Установленные версии | `%LOCALAPPDATA%\Programs\ForestRail\` (старые не удаляются) |

## Как мы работаем

- Ты говоришь, что хочешь. Я предлагаю, ты выбираешь буквой, я делаю маленькими шагами и проверяю.
- Выпуск, ярлык и релиз на GitHub только по твоему слову «выпускай». На GitHub выкладываем каждую третью версию.
- Картинки рисует GPT: я пишу задание в очередь, GPT кладёт картинки во входящие, я принимаю или пишу замечание.

## Настройка (уже сделана на этом компьютере)

Путь к Godot записан в `tools\local_settings.json`. Если компьютер новый, скопируй `tools\local_settings.example.json` в `local_settings.json` и поправь путь. Ещё нужен Python 3 с Pillow.
